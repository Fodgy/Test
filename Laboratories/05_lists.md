**Типові підводні камені:**
- `.remove(x)` видаляє за ЗНАЧЕННЯМ перше входження, а `del list[i]` — за ІНДЕКСОМ; їх часто плутають;

- `sorted(data)` створює НОВИЙ список, оригінал лишається без змін — на відміну від `.sort()`.

**Контрольна задача (без коду):** Дано список `data = [3, 1, 4, 1, 5, 9, 2, 6]`. Створи новий список, що містить тільки елементи з непарними індексами вихідного списку, у зворотному порядку, за допомогою ОДНОГО зрізу.

**Умова:** Дано список інтервалів зустрічей (список пар [початок, кінець]). Визначити мінімальну кількість переговорних кімнат, необхідних, щоб провести всі зустрічі без конфліктів (кімната звільняється рівно в момент "кінець" і одразу може прийняти нову зустріч, що починається тієї ж миті).

**Вхідні дані:** `meetings = [[0,30],[5,10],[15,20]]`

**Очікуваний результат:** 2

**Приклад:**
```text
Input: [[0,30],[5,10],[15,20]]
Output: 2
```

## Progress Check 5 (після задач 48–55, фінал теми Lists)

**Засвоєні методи/патерни:** проєктування власних структур даних поверх списків (динамічний масив), потокова обробка з частковим сортуванням, задачі рівня LeetCode Medium (3Sum, острови, медіана двох списків, переговорні кімнати), симуляції на матрицях (2048).

**Типові підводні камені на цьому рівні:**
- намагання розв'язати задачі O(n log n)/O(n) простим "перебором усіх пар" O(n²) там, де умова явно вимагає ефективності;
- забування, що список Python вже є динамічним масивом "під капотом" — реалізація власного `DynamicArray` вимагає емуляції фіксованого блоку пам'яті, а не використання вбудованого `list.append()` напряму;
- плутанина при роботі з двовимірним динамічним програмуванням (LCS) — неправильна ініціалізація базового рядка/стовпця таблиці.

**Фінальна контрольна задача теми (без коду):** Дано список цілих чисел, що представляє висоти будівель, і список запитів виду (day, height) — щодня додається нова будівля висотою `height`. Для кожного дня визнач, скільки будівель видно "з лівого краю" (будівля видна, якщо вона вища за всі попередні будівлі зліва від неї, включно з уже доданими раніше).
