
**Starter Code:**
```python

def parse_kv(line: str) -> dict:
    result = {}
    for m in re.finditer(r'(?P<k>\w+)=(?:"(?P<q>[^"]*)"|(?P<v>\S+))', line):
        result[m.group("k")] = m.group("q") if m.group("______") is not None else m.group("______")
    return result

print(parse_kv('name="Ann Lee" age=30 city=Kyiv'))
```

### Task 40 — Виявлення ризику катастрофічного повернення (ReDoS)
**Складність:** Advanced

**Умова:** Дано шаблон `r"^(\w+\.?)+@example\.com$"` для перевірки email локального домену. Переписати його в БЕЗПЕЧНИЙ (лінійний за часом) варіант із тим самим набором прийнятних значень, усунувши вкладену квантифіковану групу, що є джерелом ReDoS.

**Вхідні дані / Контекст виклику:** рядки для перевірки і, окремо, довгий «ворожий» рядок (наприклад, 20 000 символів `a`, за якими йде символ, що ламає збіг).

**Очікуваний результат:** новий шаблон дає ТІ САМІ відповіді на нормальних прикладах і обробляє ворожий рядок менш ніж за долі секунди.

**Приклад:**
```text
"a.b.c.@example.com" -> True
"a..b@example.com"    -> False
".a@example.com"      -> False
"abc@example.com"     -> True
"a@example.com"       -> True
"a.@example.com"      -> False
"@example.com"        -> False
"a b@example.com"     -> False
```

**Обмеження:**
- новий шаблон не повинен містити вкладених квантифікаторів виду `(x+)+` чи `(x*)*`.

### Task 49 — Власний спрощений движок регулярних виразів
**Складність:** Challenge

- буквальні символи;
- `.` — будь-який символ;
- `*` — нуль або більше повторів попереднього символу (жадібно, з відкатом);
- `^` на початку шаблону — прив'язка до початку рядка;
- `$` в кінці шаблону — прив'язка до кінця рядка.

Функція повинна повертати `True`, якщо шаблон збігається З БУДЬ-ЯКОЮ частиною рядка (як `re.search`), окрім випадків із явними `^`/`$`.

**Очікуваний результат:** `True`/`False`.

**Приклад:**
```text

match("^$", "")          -> True
match("x*", "abc")       -> True
match("^a", "ba")        -> False
match("a$", "ba")        -> True
match("a.*z", "a123z")   -> True
match("b$", "abc")       -> False
```

**Обмеження:**
- заборонено `import re` та будь-які інші бібліотеки регулярних виразів; лише рекурсія й порівняння символів.
